# 01｜版图设计页

## 1. 页面目标

用于自由组合和摆放桌游版图对象，定义卡牌在试玩时的放置、抽取、移动和回收规则。

## 2. 页面布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ 项目名称 ▾  版图名称 ▾  新建  撤销  重做  网格  吸附  缩放  进入试玩 │
├───────────────┬──────────────────────────────────┬─────────────────┤
│ 对象库 / 图层  │                                  │ 属性检查器       │
│               │            版图画布               │                 │
│ 可拖拽对象     │                                  │ 位置、尺寸、样式  │
│ 图层树         │                                  │ 绑定卡牌、行为    │
└───────────────┴──────────────────────────────────┴─────────────────┘
```

推荐桌面端最小宽度 1280px。左栏宽 240px，右栏宽 300px，中间画布自适应。

## 3. 顶部工具栏

| 控件 | 说明 |
|---|---|
| 项目名称 | 切换当前桌游项目 |
| 版图名称 | 切换、重命名、复制或删除版图 |
| 新建版图 | 创建空白版图或从模板创建 |
| 撤销 / 重做 | 撤销对象增删、移动、属性修改 |
| 网格 | 显示或隐藏网格 |
| 吸附 | 对象移动时吸附到网格或其他对象边缘 |
| 缩放 | 25%—200%，并提供“适应画布” |
| 预览 | 隐藏编辑辅助线，查看最终版图外观 |
| 进入试玩 | 使用当前版图启动试玩页 |

## 4. 左侧对象库

### 4.1 对象库标签

- `对象库`：添加新的版图对象。
- `图层`：查看和管理当前版图中的对象。

### 4.2 可用对象

| 对象 | 默认图标/颜色 | 设计用途 | 试玩规则                                                                |
|---|---|---|-------------------------------------------------------------------------|
| 卡牌放置格 | 蓝色单格 | 放置一张指定或任意卡牌 | 同一时刻最多一张牌                                                      |
| 卡牌放置区 | 绿色区域 | 平铺任意数量卡牌 | 支持横向、纵向、网格或扇形排列                                          |
| 卡组放置区 | 紫色牌堆 | 放置一个卡组对象并抽牌 | 点击或拖拽抽取顶牌，支持一键洗牌                                        |
| 卡堆 | 橙色牌堆 | 弃牌区、除外区或自定义牌堆 | 支持叠放、查看、洗牌和取顶牌，支持一键移动所有牌到另一个卡堆/卡组放置区 |

对象库卡片显示对象名称、简短说明和拖拽手柄。双击对象卡片也可添加到画布中心。

## 5. 中央版图画布

### 5.1 画布能力

- 拖拽、缩放、旋转对象。
- 框选和多选对象。
- 对齐、等距分布、复制、粘贴、删除。
- 图层前置、后置。
- 网格、标尺、参考线和吸附。
- 设置画布宽度、高度、背景色或背景图。
- 空白画布显示引导语：“从左侧拖入一个对象开始设计”。

### 5.2 编辑态视觉

- 选中对象显示边界框、八个缩放控制点和旋转控制点。
- 对象左上角显示名称，右下角显示容量或绑定信息。
- 蓝、绿、紫、橙四种边框对应四类核心对象。
- 锁定对象显示锁图标，隐藏对象在图层面板中置灰。

## 6. 右侧属性检查器

### 6.1 通用属性

| 分组 | 字段 |
|---|---|
| 基础信息 | 名称、对象类型、备注 |
| 位置与尺寸 | X、Y、宽度、高度、旋转角度 |
| 外观 | 背景色、边框颜色、边框宽度、圆角、阴影、透明度 |
| 编辑状态 | 锁定、隐藏、是否显示名称 |
| 试玩行为 | 是否允许拖出、是否允许查看、是否允许放回 |

### 6.2 卡牌放置格专属属性

- 绑定卡牌：指定单卡或留空表示任意卡牌。
- 是否显示卡背。
- 是否允许替换已有卡牌。
- 是否允许玩家拿走。
- 空位提示文字。

### 6.3 卡牌放置区专属属性

- 排列方向：横向、纵向。
- 排列方式：平铺、网格、扇形。
- 卡牌间距和边距。
- 最大可见数量；超出时显示数量徽标。
- 是否允许重叠。
- 是否显示区域名称。

### 6.4 卡组放置区专属属性

- 绑定卡组。
- 初始是否自动洗牌。
- 抽牌方式：点击抽牌、拖拽抽牌。
- 是否显示剩余牌数。
- 是否允许查看牌堆。
- 抽出的卡牌默认进入的区域。

### 6.5 卡堆专属属性

- 堆名称：弃牌区、除外区或自定义名称。
- 显示正面或背面。
- 是否允许查看全部卡牌。
- 是否允许洗牌。
- 取牌方式：顶牌或任意牌。
- 是否允许回收至指定卡组。

## 7. 图层面板

图层以树状列表显示，支持重命名、锁定、隐藏、层级调整、复制、删除、多选和搜索。

```text
版图
├── 卡组放置区：事件牌堆
├── 卡堆：弃牌区
├── 卡牌放置区：玩家区域
└── 卡牌放置格：起始卡
```

## 8. 关键交互

1. 从对象库拖入对象后，自动选中并打开属性检查器。
2. 删除绑定卡组的放置区时，提示“仅删除版图对象，不删除卡组”。
3. 绑定资源不存在时显示警告，并允许重新选择。
4. 试玩预览中隐藏网格、辅助线、选中框和编辑名称。

## 9. 页面验收标准

- 四类核心对象均可添加、移动、缩放、复制和删除。
- 属性修改可实时反映在画布上。
- 版图对象的绑定关系刷新后仍然存在。
- 版图可以从试玩页正确读取。
- 所有变更均可撤销并自动保存到 IndexedDB。
