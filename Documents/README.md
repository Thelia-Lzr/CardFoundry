## 全局 UI 约定

- 顶部固定主导航：`桌游设计`、`桌游试玩`、`文件导出`。
- 桌游设计下使用二级导航切换 `版图设计`、`单卡设计`、`卡组设计`。
- 所有编辑内容自动保存到浏览器 IndexedDB。
- 顶部持续显示保存状态：`已保存`、`保存中`、`保存失败`。
- 支持撤销、重做、键盘快捷键和帮助入口。
- 设计数据与试玩数据分开保存。
