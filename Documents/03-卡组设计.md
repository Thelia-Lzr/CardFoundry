# 03｜卡组设计页

## 1. 页面目标

用于创建由单卡组成的卡组，设置每张单卡的数量，并通过 XLSX 快速生成卡组成员关系。

## 2. 页面布局

```text
┌──────────────────────────────────────────────────────────────────┐
│ 桌游设计 / 卡组设计   新建卡组  导入 XLSX  添加单卡  导出当前卡组 │
├────────────────┬─────────────────────────────────────────────────┤
│ 卡组列表         │ 卡组详情                                        │
│ 搜索、排序       │ 名称、描述、成员表格、数量统计、卡组预览          │
└────────────────┴─────────────────────────────────────────────────┘
```

## 3. 左侧卡组列表

每个列表项显示卡组名称、卡牌种类数、实际卡牌总数和最近更新时间。支持新建、复制、重命名、删除、搜索和排序。删除卡组只删除卡组关系，不删除其中引用的单卡。

## 4. 卡组详情区

### 4.1 基本信息

- 卡组名称、描述和标签。
- 卡组背面样式。
- 是否允许在版图中绑定。

### 4.2 成员表格

```text
┌──────┬──────────────┬──────┬────────────┬────────────┐
│缩略图│ 卡牌名称      │数量  │ 标签        │ 操作        │
├──────┼──────────────┼──────┼────────────┼────────────┤
│      │ 起始卡        │ 4    │ 基础        │ 编辑 / 移除  │
│      │ 火球术        │ 2    │ 法术        │ 编辑 / 移除  │
└──────┴──────────────┴──────┴────────────┴────────────┘
```

成员表格支持添加已有单卡、输入数量、移除成员、批量修改数量、排序和点击卡牌名称进入单卡设计页。数量必须是大于等于 0 的整数。

### 4.3 统计卡片

页面顶部显示卡牌种类数、卡牌总数、标签数量、缺失单卡数量和数量为 0 的成员数量。

## 5. XLSX 导入卡组

### 5.1 推荐格式

| 卡名 | 数量 | 标签 |
|---|---:|---|
| 起始卡 | 4 | 基础 |
| 火球术 | 2 | 法术 |
| 治疗术 | 3 | 回复 |

### 5.2 导入流程

```text
选择 XLSX → 选择工作表 → 映射卡名、数量、标签列
→ 匹配现有单卡 → 处理未匹配卡牌 → 确认导入卡组
```

### 5.3 未匹配卡牌处理

- 自动创建空白单卡，并标记“待完善”。
- 跳过未匹配行。
- 保留为错误项，导入后手动处理。

重复卡名默认合并数量，并在预览中显示合并提示。数量不是正整数时标记错误。

## 6. 卡组预览

提供 `列表视图` 和 `卡牌墙视图`。可选显示数量徽标、卡牌背面、标签分组和稀有度分组。

## 7. 与版图、试玩的关系

- 版图中的“卡组放置区”绑定一个卡组。
- 试玩开始时，按照成员数量生成实际牌堆。
- 单卡内容修改后，卡组成员预览自动同步。
- 删除单卡时，卡组保留缺失引用并显示警告，不静默删除成员。

## 8. 页面验收标准

- 可以创建、复制、编辑、删除卡组。
- 可以添加已有单卡并设置数量。
- XLSX 导入可以正确匹配、合并和报告错误。
- 卡组总数与成员数量之和一致。
- 卡组可被版图绑定并在试玩中抽取。
- 所有卡组修改均自动保存到 IndexedDB。
