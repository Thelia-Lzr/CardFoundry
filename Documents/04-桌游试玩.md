# 04｜桌游试玩页

## 1. 页面目标

将已设计的版图、单卡和卡组转换为可操作的桌游原型，用于验证流程、抽牌、摆牌和弃牌逻辑。

## 2. 页面布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ 项目 ▾  版图 ▾  玩家数  当前玩家  开始/暂停  重开  保存试玩  返回设计 │
├────────────────┬──────────────────────────────────┬─────────────────┤
│ 玩家与牌组      │                                  │ 当前对象 / 牌组  │
│ 玩家列表        │            试玩版图               │ 游戏日志         │
│ 手牌            │                                  │ 操作按钮         │
└────────────────┴──────────────────────────────────┴─────────────────┘
```

中央试玩区域占据主要空间，编辑辅助线和网格默认隐藏。

## 3. 顶部控制栏

| 控件 | 说明 |
|---|---|
| 项目 | 选择当前桌游项目 |
| 版图 | 选择要试玩的版图 |
| 玩家数 | 设置玩家数量并创建玩家区域 |
| 当前玩家 | 切换回合或当前操作玩家 |
| 开始 / 暂停 | 控制试玩状态 |
| 重开 | 按当前版图和卡组重新生成牌堆 |
| 撤销一步 | 撤销最近一次移动、抽牌或翻牌 |
| 保存试玩 | 保存独立的试玩会话 |
| 返回设计 | 回到上一次设计页面 |

## 4. 左侧玩家与资源栏

### 4.1 玩家列表

每位玩家显示玩家名称和颜色、当前行动状态、手牌数量、个人区域卡牌数量及预留的完成/淘汰状态。

### 4.2 手牌区

选择玩家后显示该玩家手牌，支持正面或背面显示、排序、查看详情和拖入版图对象。默认其他玩家看不到手牌正面。

## 5. 中央试玩版图

设计页中的四类对象在试玩中成为交互区域：

- **卡牌放置格**：拖入一张卡牌；按规则替换、翻面、拿走或移动。
- **卡牌放置区**：接收任意数量卡牌，按平铺、网格或扇形排列。
- **卡组放置区**：点击或拖拽抽取顶牌，显示或隐藏剩余牌数，并按配置放入指定区域或手牌。
- **卡堆**：叠放并显示数量，支持取顶牌、查看全部、洗牌和回收。

## 6. 右侧操作面板

右侧使用三个标签：`当前对象`、`牌组`、`游戏日志`。

### 6.1 当前对象

选中卡牌时显示卡名、效果、标签、当前位置、翻面、移动到其他区域、放入弃牌区和放回卡组。选中区域时显示区域名称、卡牌数量、抽牌、洗牌、查看和清空操作。

### 6.2 牌组

显示每个卡组的总牌数、剩余牌数、抽牌、洗牌、查看牌堆和从弃牌区回收。

### 6.3 游戏日志

```text
玩家1 从事件牌组抽取了“火球术”
玩家1 将“火球术”放入玩家区域
玩家2 将一张牌放入弃牌区
事件牌组已洗牌
```

## 7. 试玩状态模型

试玩状态与设计数据分离保存，至少包括当前版图、当前玩家、每个卡组的剩余牌序、实体卡牌位置和正反面、玩家手牌、游戏日志及时间信息。

设计者修改卡牌或版图后，已有试玩会话提示“设计已更新，是否按新设计重新开始”。

## 8. 空状态与异常处理

- 未选择版图：显示“选择版图开始试玩”。
- 版图绑定的卡组不存在：阻止开始并显示修复入口。
- 卡组为空：允许预览版图，但不能抽牌。
- 抽牌区为空：显示“牌堆已空”，不产生异常卡牌。
- 操作无效：使用就地提示，不打断当前试玩。

## 9. 页面验收标准

- 可以从版图启动试玩并读取所有对象。
- 可以抽牌、移动、翻面、放入卡牌区域和卡堆。
- 卡组数量、牌序和玩家手牌状态正确保存。
- 游戏日志能够记录关键操作。
- 刷新页面后可以恢复已保存试玩会话。
