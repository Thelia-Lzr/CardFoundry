# 02｜单卡设计页

## 1. 页面目标

用于创建、编辑、预览和批量导入单张卡牌。卡牌效果支持富文本，可保留从飞书复制的文字颜色和底色。

## 2. 页面布局

```text
┌──────────────────────────────────────────────────────────────────┐
│ 桌游设计 / 单卡设计   新建单卡  导入表格  批量操作  预览  保存状态 │
├────────────────┬─────────────────────────────┬───────────────────┤
│ 单卡列表         │ 编辑器 / 卡牌实时预览        │ 卡片属性            │
│ 搜索、筛选、缩略图 │                             │ 模板、尺寸、标签     │
└────────────────┴─────────────────────────────┴───────────────────┘
```

## 3. 顶部工具栏

- `新建单卡`：创建空白单卡并自动聚焦卡名。
- `导入表格`：导入 XLSX、CSV 或粘贴飞书表格。
- `批量操作`：批量删除、打标签、加入卡组。
- `编辑 / 预览`：切换富文本编辑态与实际卡面。
- `复制`：复制当前卡牌并生成新编号。
- `保存状态`：显示自动保存结果。

## 4. 左侧单卡列表

列表项显示卡牌缩略图、卡名、标签或稀有度、卡牌编号。支持：

- 按卡名搜索。
- 按标签、稀有度、所属卡组筛选。
- 按名称、创建时间、更新时间排序。
- 多选卡牌。
- 拖拽单卡到卡组成员区域。

空状态提供 `新建单卡` 和 `导入表格` 两个操作。

## 5. 中央编辑器

### 5.1 卡牌字段

- 卡名。
- 卡牌效果（核心富文本字段）。
- 卡牌说明或规则提示。
- 插图或图标。
- 标签、稀有度、卡牌编号。
- 自定义字段。
- 卡牌正面和背面样式。

### 5.2 富文本工具栏

```text
粗体  斜体  下划线  删除线  文字颜色  底色
标题  对齐  有序列表  无序列表  缩进  清除格式
```

富文本内部保存为安全 HTML 与结构化样式数据，避免重新打开时丢失颜色信息。

### 5.3 飞书文字粘贴

粘贴时优先读取剪贴板 HTML：

1. 保留文字颜色和文字底色。
2. 保留粗体、斜体、下划线。
3. 尽可能保留段落、列表和表格结构。
4. 不支持的样式转换为最接近的卡牌样式。
5. 过滤脚本、事件属性和不安全链接。

粘贴后显示轻量提示，例如：“已保留 3 种文字颜色和 2 种底色”。

### 5.4 卡牌实时预览

```text
┌────────────────────┐
│       卡名          │
│                    │
│    插图 / 图标      │
│                    │
│  卡牌效果文字       │
│  支持颜色、底色      │
│                    │
│ 编号       稀有度    │
└────────────────────┘
```

支持正面 / 背面预览、缩放和不同卡牌尺寸预览。
卡牌效果按照卡效字数自动调整大小，可换行

## 6. 右侧卡片属性

### 6.1 模板与尺寸

- 卡牌模板：默认、简约、战斗、事件、自定义。
- 宽度、高度、圆角。
- 正面背景和背面背景。
- 边框、阴影和字体。

### 6.2 元数据与图片

- 标签、稀有度、卡牌编号、所属卡组和备注。
- 上传或粘贴本地图片。
- 图片裁切方式：填充、适应、原图。
- 替换、删除图片并显示占用大小。

## 7. 表格批量导入

支持 `.xlsx`、`.csv` 和从飞书表格直接粘贴。

```text
选择文件 → 选择工作表 → 字段映射 → 数据预览 → 确认创建
```

| 表格列 | 单卡字段 |
|---|---|
| 卡名 | 卡名 |
| 卡牌效果 | 卡牌效果 |
| 卡牌说明 | 卡牌说明 |
| 标签 | 标签 |
| 稀有度 | 稀有度 |
| 图片地址 | 卡牌插图 |
| 数量 | 导入数量（可选） |

导入预览标记缺少卡名、重复卡名、空效果、数量格式错误和无效图片地址。用户可选择跳过错误行或取消导入。

## 8. 页面验收标准

- 新建、编辑、复制、删除单卡均可用。
- 粘贴飞书富文本后，颜色和底色在编辑器与预览中一致。
- XLSX 导入可以自定义字段映射，并在确认前预览结果。
- 图片资源与单卡一起保存，刷新后仍可显示。
- 单卡可以被多个卡组引用，修改后卡组预览同步更新。
- 自动保存、撤销和重做覆盖文本、样式、图片和元数据变更。
